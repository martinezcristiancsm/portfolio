SISTEMA DE GESTIÓN · PRODUCCIÓN PROPIA

App de gestión para un emprendimiento real de jardinería y paisajismo. Cubre clientes, tareas sincronizadas con el calendario nativo, presupuestos con generación de PDF, y un módulo de "Diseño IA" que edita fotos de jardines con instrucciones en lenguaje natural. Uso diario desde iPhone/iPad en el campo.

Java 21Spring Boot 3.5PostgreSQL 16Docker React NativeExpo SDK 57TypeScriptOpenAI API

Decisiones de arquitectura

  • Dinero sin errores de redondeo: BigDecimal en el backend; en el frontend, un input de moneda enmascarado tipo cajero automático que evita los bugs clásicos de parseo "," vs "."
  • Zona horaria explícita: el backend corre forzado en UTC por una limitación del tzdata de Postgres en Windows; todo timestamp de negocio pasa por un helper que calcula la hora real de Argentina.
  • Imágenes fuera del JSON principal: se guardan como bytea en tablas dedicadas y se sirven por un endpoint aparte, nunca como base64 embebido.
